## Narration, read straight through

Here's how building with AI works right now. A harness runs the agents. Skills tell them how to do things. Tools let them reach your systems.

All of that is about how the agent works. None of it holds what you're building.

So every session starts from zero. Memory files rot, because a person has to keep them current. And when two agents touch the same thing, nobody knows what changed.

Dandy is the state layer. One graph of your product: projects, typed inputs and outputs. Every agent reads it before it starts, writes back what it changed, and the change flows downstream. Every write is on the record.

Which gets you three things. You pick up where you left off. Plan and code stop being two sources of truth. And it works with whatever harness you already use.

Dandy is the state layer.
