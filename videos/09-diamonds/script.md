# 09 Just the Diamonds

**Takeaway:** A big context window is mostly junk by the time you are deep in a build. The few things that matter are buried in it. Dandy keeps those in one place as a live map of the project; the agent reads it first and writes back what it changed.

**Kind:** metaphor video. No Dandy Man. Own look; shares the copy rules, the safe zones and the soft end card.
Names Claude Code outright. Sits beside 08 (what a context window is) as the short follow-up: what is actually in it.

**Look:** a tall glass column on a near-black ground, filling the vertical frame. That column is the context
window. Junk falls into it as dull grey and brown rubble, each piece a small tagged chip. Diamonds are the only
bright thing in the first half: cold white with a cyan glint. A thin fill meter runs up the side of the glass. The
agent is a single small cursor of light that searches the pile. Dandy is a purple display case that slides in
beside the column: the same diamonds, lifted out, laid flat and joined by thin lines, so the case reads as a map.
Purple appears nowhere before that moment. Motion is quick and physical: things drop, settle, get sifted. Hard
cuts, no slow builds.

**Audience:** individual builders using Claude Code. No terms to define.

**Target length:** 23.5 s as recorded (50 narrated words). Still the shortest video so far. Status: v3 approved Nov 11, narrated Nov 12; was for
Charlie's review. No render until the words are approved.

## Accuracy notes

- "Huge" and no number: the window size depends on the model, so the script never states one.
- "Starts slipping long before it's full": quality dropping as the window fills, well before the limit, is widely
  reported for Claude Code, and its own guidance is to compact or clear when context starts affecting performance.
  The meter in beat 2 stops under half and shows no exact threshold, because no single number is agreed on.
- "Junk" is shorthand. Those file reads and logs were useful when they happened; they are stale now and still
  taking up room. The visual carries that (rubble that piles up), the narration keeps the short word.
- "A live map of your project": the product graph (the projects, how they connect, the status of each). "Kept
  current by your agent": agents read it before they start and write back what they changed, through Dandy's
  connection to Claude Code.
- The script does not claim Dandy uses fewer tokens or makes the window bigger.
