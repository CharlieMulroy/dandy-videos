# 10 What is Dandy?

**Takeaway:** Dandy is where your project lives: a live map of every piece and how they connect, which your agent reads before it starts and updates when it is done.

**Kind:** informational, about Dandy. Dandy Man presents. First of the pinned series (10 What, 11 How, 12 Why);
each one stands alone, because pinned videos get watched in any order.

**Look:** Void Stage, new for this series. Dandy Man floats in a dark purple void, bottom right, bobbing gently and
pointing up at whatever is being explained. The visuals float in the open space above him, with no board or frame.
One short key phrase sits bottom left, beside him, and captions run under both, one line at a time. Brand purple throughout; the agent is the same small cursor of
light as in video 09. Quick, springy motion; things pop in as they are named.

**First frame (thumbnail):** a still title card, "What is Dandy?", in large type with Dandy Man beneath it. It holds
for half a second before anything moves, so the first frame and the cover are the same picture. Also exported as
out/10-thumbnail.png for upload as a cover.

**Audience:** individual builders who have never heard of Dandy. No terms to define.

**Target length:** about 30 s (67 narrated words). Status: draft v1, Nov 12, for Charlie's review. First render made
alongside it because Charlie was away; words are still open to change.

## Narration, read straight through

What is Dandy?

When you build with AI, every new session starts from zero.
Your agent doesn't know what's built, what's decided, or what's next.

Dandy is where your project lives.
A live map of every piece, and how they connect.

Your agent reads it before it starts, and updates it when it's done.

So every session picks up right where the last one left off.
That's Dandy.

## Accuracy notes

- "Every new session starts from zero": a fresh agent session has no memory of earlier ones unless it is given
  something to read. True of Claude Code and its peers.
- "A live map of every piece, and how they connect": the product graph (projects, the edges between them, and each
  one's status). Same wording as video 09, on purpose.
- "Reads it before it starts, and updates it when it's done": how agents use Dandy through its connection.
- The pieces on screen are a made-up booking app, not a customer's project.
- No claim about tokens, speed or cost.

## Messaging check

- Problem first (beat 1), then what Dandy is, then how it stays current, then the payoff.
- Does not call Dandy a project management tool, a harness or a framework; no "state layer"; no long dashes.
- Dandy Man appears because this is an informational video about Dandy; end card with him.
