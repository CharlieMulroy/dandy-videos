## Narration, read straight through

How does Dandy work?

You connect it to your AI coding tool, once.

Tell your agent what you're building, and it lays it out as a map:
every piece, and how they connect.

Before it builds, your agent reads the map.
When a piece is finished, a second check confirms it before it counts as done.

And when one piece changes, Dandy flags everything it touches.

So the map stays current, and you never update it by hand.

## Accuracy notes

- "Connect it once": Dandy connects to the coding tool through a connector, set up one time. The script says "your
  AI coding tool" and does not name Claude Code; Charlie's call whether to name it.
- "Lays it out as a map": the agent creates the pieces and the connections between them from the description.
- "A second check confirms it": a piece only counts as done after a separate review pass signs off on it; the
  reviewer is never the same session that built it. Shown as a second light.
- "Flags everything it touches": when a piece's shape changes, the change flows along its connections to the pieces
  that depend on it. The video shows the two pieces Bookings feeds being flagged.
- "You never update it by hand": the agent keeps it current as part of the work. People can still edit it; the
  line is about not having to.
- This is the video that describes mechanics, so it should get a read from Nick before recording.
- No claim about tokens, speed or cost.
